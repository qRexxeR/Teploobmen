# Практика 2 — Теплообмен в противотоке

Веб-приложение на **C# / ASP.NET Core MVC, .NET 8** для стационарного теплообмена газа и термически тонкого кускового материала в плотном продуваемом слое. Начальные данные соответствуют варианту 16.

## Запуск в Visual Studio 2022

1. Откройте `Teploobmen.sln`. Нужна рабочая нагрузка «ASP.NET и веб-разработка» и поддержка .NET 8.
2. Выберите `Teploobmen` запускаемым проектом и профиль **http**.
3. Нажмите **Ctrl+F5** или **F5**. Адрес приложения: **http://localhost:5196**.

Из командной строки в корне репозитория:

```powershell
dotnet restore Teploobmen.sln
dotnet build Teploobmen.sln
dotnet run --project Teploobmen --launch-profile http
```

## Возможности

- Редактирование геометрии, температур, расходов, теплоемкостей, коэффициента теплоотдачи и шага расчета.
- Таблица температур материала `t(y)`, газа `T(y)` и разности `T(y) − t(y)`.
- Две интерактивные диаграммы с подписями осей, легендой и значениями под указателем.
- Сохранение именованных вариантов, повторное открытие и удаление; данные сохраняются после перезапуска.
- Экспорт текущего расчета в CSV с UTF-8 BOM и разделителем `;` для Excel.
- Серверная проверка чисел, положительности параметров и ограничения до 2001 точки. Можно вводить десятичную запятую или точку.
- Адаптивное оформление и отдельная страница методики расчета. Внешние CDN не используются.

## Проверка

```powershell
dotnet run --project Teploobmen.Tests
```

Это автономный набор проверок без стороннего тестового фреймворка. При успехе процесс завершается с кодом 0, при ошибке — с ненулевым кодом.

Контроль варианта 16: `H = 6 м`, `D = 2,3 м`, `t′ = 0 °C`, `T′ = 700 °C`, `wг = 0,72 м/с`, `Cг = 0,9 кДж/(м³·К)`, `Gм = 1,66 кг/с`, `Cм = 1,49 кДж/(кг·К)`, `αV = 2430 Вт/(м³·К)`.

Ожидаемые результаты: материал на выходе **691,114859 °C**, газ на выходе **65,072661 °C**, тепловой поток **1709,403493 кВт**.

## Математическая модель

Координата `y` направлена от верхней границы слоя вниз. Материал входит при `y = 0`, газ — при `y = H`. Теплоемкости из кДж переводятся в Дж. Скорость газа относится к полному свободному сечению шахты.

`S = πD²/4`, `Vг = wгS`, `Wм = GмCм·1000`, `Wг = VгCг·1000`, `m = Wм/Wг`, `Y = αVSy/Wг`.

При `m ≠ 1`: `k = (m − 1)/m`, `d = 1 − m·exp(kY₀)`, `ϑ = (1 − exp(kY))/d`, `θ = (1 − m·exp(kY))/d`.

При `m = 1`: `ϑ = Y/(1 + Y₀)`, `θ = (1 + Y)/(1 + Y₀)`.

`t = t′ + (T′ − t′)ϑ`, `T = t′ + (T′ − t′)θ`. В реализации используются устойчивые эквивалентные выражения. Поддерживаются нагрев и охлаждение; знак теплового потока положителен при нагреве материала. При равных входных температурах поток равен нулю, эффективность условно отображается как 0.

Допущения: стационарность, постоянные расходы и свойства, одинаковая температура внутри каждого куска, отсутствие потерь через стенки, продольной теплопроводности и перемешивания по высоте.

## Сохраненные данные

Файл `Teploobmen/App_Data/calculations.json` создается при первом сохранении и исключен из Git. Результаты пересчитываются из сохраненных исходных данных. Приложение предназначено для локальной учебной работы; аутентификация и разграничение пользователей не реализованы. Для нескольких серверных процессов следует заменить файловое хранилище базой данных.
